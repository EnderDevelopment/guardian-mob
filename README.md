# GuardianMob

GuardianMob is a Minecraft plugin that introduces a mobile mob designed to patrol and defend its spawn area. This mob will actively target hostile entities, villagers, and iron golems when players are within its vicinity. The plugin is built using the PaperMC API and is designed to enhance the gameplay experience by adding a dynamic and aggressive mob to the game.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to load the plugin.

## Use

1. Start your Minecraft server with the plugin installed.
2. Use the command `/spawnmobilemob` to spawn a GuardianMob at your current location.
3. The GuardianMob will automatically patrol its spawn area
